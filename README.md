# Coffee Daily

Coffee Daily is an online ordering site for a coffee chain. Customers pick a pickup location, browse a menu filtered by that location's stock, configure a drink, pay with Stripe, and track their order.

## Status

Early foundation phase. No application code yet.

## Stack

Next.js, TypeScript, NestJS, Tailwind CSS, Three.js (React Three Fiber), GSAP, Zustand, Stripe, Bun, Turborepo.
